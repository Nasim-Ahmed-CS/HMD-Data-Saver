# Device Frame Capture

This folder contains a simple Unity script for saving device or camera frames to disk during a study session.

## Script
- `DeviceFrameCapture.cs` — captures frames from a selected camera and saves them as PNG/JPG images in the participant data folder.

## Purpose
This is useful for recording visual data from the HMD or passthrough camera stream for later analysis, synchronization, or offline review.

## Notes
The script is intentionally kept simple and standalone so it can be added to a Unity scene without changing the rest of the project structure.
